Repositorio de Videojuegos Web y Pasatiempos HTML

Estado del Proyecto
Nota de desarrollo: Este repositorio recopila proyectos personales, prototipos y desarrollos lúdicos web creados como pasatiempo y experimentación técnica.

Descripción General
Este repositorio funciona como un espacio de almacenamiento y exhibición para diversos videojuegos y aplicaciones interactivas ligeras desarrolladas en tecnologías web nativas. Su propósito principal es explorar mecánicas de juego, lógica de programación en el cliente y diseño de interfaces lúdicas sin dependencias complejas.

Estructura y Tecnologías
Requisitos del Sistema
Cualquier navegador web moderno con soporte para HTML5, CSS3 y JavaScript (ES6+).

Entorno de ejecución local opcional (Live Server o similar) para pruebas de desarrollo.

Stack Tecnológico
Estructura: HTML5 semántico.
Estilos: CSS3 nativo (flexbox, grid, animaciones).
Lógica: JavaScript puro (Vanilla JS) para la gestión de bucles de juego, eventos y renderizado en DOM o Canvas.

Lista de Proyectos Incluidos
El repositorio agrupa de manera independiente diversos minijuegos y pasatiempos, cada uno contenido en su propio directorio o archivo ejecutable:

Prototipos de lógica y rompecabezas.
Pruebas de mecánicas arcade en 2D.
Pasatiempos clásicos adaptados a la web.

Ejecución y Uso Local
Clona o descarga el repositorio en tu equipo local.
Abre cualquier archivo HTML principal directamente en tu navegador web de preferencia, o bien, ejecuta el entorno de desarrollo local para una mejor gestión de recursos.
